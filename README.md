Projet de Master 1 – Technologie Web et Multimédia  
Université [Nom de votre université]  
Étudiant : Rodriguez Oma

##  Présentation

Ce projet propose une **plateforme web immersive** dédiée à **l’art numérique contemporain**. Il combine :
- Une interface web responsive (desktop & mobile)
- Des contenus multimédias (vidéos, infographies, audio)
- Une **expérience 3D interactive en temps réel** directement dans le navigateur (sans plugin)

L’objectif est de rendre l’art numérique **accessible, pédagogique et ludique** pour un large public.

## Technologies utilisées

- **Frontend** : React, Vite
- **3D** : Three.js (WebGL)
- **Routage** : React Router
- **Déploiement** : GitHub Pages
- **Design** : CSS moderne, responsive
